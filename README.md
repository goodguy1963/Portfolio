# Marcel Hofer — Portfolio

Static portfolio and case-study site for `goodguy1963.github.io/Portfolio/`.

Featured cases: ProductBackground, Copilot Cockpit, ThinkingLLM, [Comfy Rail](https://comfyrail.dev), and [3DOfficeAT](https://3doffice.at).

## Local preview

Serve the repository root with any static HTTP server, for example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173/`.

The site intentionally has no build step, analytics, cookies, form backend, or runtime dependency.

Pushes to `master` deploy automatically through the GitHub Pages workflow. A manual workflow dispatch remains available for recovery deployments.
